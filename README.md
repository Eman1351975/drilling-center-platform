## نبذة عن المشروع

**منصة مركز الحفر** مبادرة لتطوير إجراءات إدارة مخرجات الدورات التدريبية، تجمع بين إعداد شهادات المشاركين وفق القالب المعتمد لدى مركز الحفر، وتحليل إجابات استمارات التقييم وإخراج تقارير قابلة للحفظ والمشاركة.

تساعد المنصة على تقليل الإدخال المتكرر والعمل اليدوي، وتوحيد شكل الشهادات والتقارير، وتسريع إعداد مخرجات الدورة. وقد جرى تطويرها بالاستعانة بأدوات الذكاء الاصطناعي، مع توفير وظائف تعمل مباشرة في المتصفح.

## القسم الأول: إصدار الشهادات

تُنشئ المنصة شهادات المشاركة اعتمادًا على قالب مركز الحفر المضمّن في التطبيق، مع تحديث بيانات الدورة والمشاركين.

### بيانات الشهادة

| البيان | طريقة الاستخدام |
| --- | --- |
| أسماء المشاركين | إدخال اسم كل مشارك في سطر مستقل، أو استخراج الأسماء من ملف |
| مستوى الدورة | تحديد المستوى، مثل L2 أو L4 |
| فترة الدورة | إدخال أو مراجعة تاريخ بداية الدورة ونهايتها |
| رقم الدورة | إدخاله ليظهر بجانب كلمة course أسفل رمز QR |

يمكن إدخال البيانات مباشرة، أو تحميل ملف يتضمن معلومات المشاركين والدورة. يدعم التطبيق ملفات PDF وWord بصيغة DOCX والنصوص والصور، مع اختلاف دقة الاستخراج حسب تنسيق الملف ووضوحه. تُراجع البيانات المستخرجة قبل إصدار الشهادات.

### خيارات التنزيل

| الزر | الناتج |
| --- | --- |
| تحميل الأول PDF | شهادة أول مشارك بصيغة PDF |
| تحميل كل الشهادات (ZIP) | ملف ZIP يحتوي على شهادة PDF مستقلة باسم كل مشارك |
| ملف PDF واحد لكل الشهادات | ملف PDF مجمّع يضم شهادات جميع المشاركين |

تُجهّز الشهادات آليًا وبسرعة، ويختلف زمن التنفيذ حسب عدد المشاركين وحجم المخرجات وقدرة الجهاز؛ ولا تفترض المنصة زمنًا ثابتًا لجميع الأحجام.

### صورة قسم الشهادات

*توضح الصورة حقول المستوى ورقم الدورة والفترة وأسماء المشاركين، ومعاينة الشهادة وفق القالب المضمّن، وأزرار التنزيل الثلاثة.*

## القسم الثاني: تحليل التقييمات

يقرأ هذا القسم نتائج استبيانات المشاركين من ملف Excel، ويحوّلها إلى تقرير يتضمن مؤشرات رقمية واستنتاجات ورسمًا بيانيًا. يدعم رفع XLSX وXLS وCSV المتوافقة مع بنية النموذج.

### محتويات التقرير

- بيانات البرنامج التدريبي ورقم الدورة وتاريخ انعقادها.
- رقم التقرير وتاريخه وعدد استجابات المشاركين.
- أسماء المحاضرين.
- تحليل ثلاثة محاور: **تقييم المدرب، المادة العلمية، وتنظيم البرنامج التدريبي**.
- نسب التقييم والوصف المقابل لها واستنتاجات مكتوبة تلقائيًا.
- ملاحظات المشاركين ومقترحاتهم.
- رسم بياني للمقارنة بين المحاور.

تظهر نتيجة التحليل على الشاشة بعد قراءة الملف، ويمكن مراجعة بيانات التقرير وتعديلها قبل الحفظ، مع إمكانية اختيار بدء محور الرسم البياني من الصفر.

### خيارات حفظ التقرير

| الزر | الناتج |
| --- | --- |
| حفظ PDF | تقرير بصيغة PDF |
| حفظ كصورة JPG | صورة للتقرير قابلة للحفظ والمشاركة |

## خطوات الاستخدام

### إعداد شهادات دورة

1. افتح المنصة واختر تبويب **الشهادات**.
2. اكتب أسماء المشاركين، كل اسم في سطر، أو ارفع ملف البيانات.
3. راجع الأسماء ومستوى الدورة ورقمها وفترتها.
4. تحقق من المعاينة، خاصة ترتيب التاريخ وكتابة الأسماء.
5. اختر تنزيل أول شهادة أو الشهادات المنفصلة داخل ZIP أو ملف PDF المجمّع.

### إعداد تقرير تقييم

1. اختر تبويب **التقييم**.
2. ارفع ملف نتائج الاستبيان بصيغة متوافقة مع المثال المرفق.
3. راجع بيانات الدورة والمحاضرين وعدد الاستجابات.
4. اطلع على النتائج والملاحظات والرسم البياني.
5. احفظ التقرير بصيغة PDF أو صورة JPG.
